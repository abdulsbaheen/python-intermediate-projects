# File Renamer

A simple Python program that allows users to rename files easily. The program provides two options:

1. **Rename File Name** – Change the name of a file while keeping its extension unchanged.
2. **Rename File Extension** – Change the file extension while keeping the original file name.

The user selects the desired operation, enters the required information, and the program performs the renaming automatically.
