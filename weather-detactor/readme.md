# 🌤️ Weather Detector (Python CLI)

A simple **Command-Line Weather Detector** built with **Python** that fetches real-time weather information using the **OpenWeatherMap API**. Users can enter any city name and instantly receive the current weather conditions in the terminal.

> This project was created to practice working with **REST APIs**, **HTTP requests**, **JSON data**, and **Python programming**.

---

## 🚀 Features

- 🌍 Search weather by city name
- 🌡️ Display current temperature
- ☁️ Show weather description
- 💧 Display humidity
- 🌬️ Display wind speed
- ⚡ Fetch real-time weather data using an API
- 🖥️ Simple command-line interface

---

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/weather-detector.git
```

### Navigate to the project folder

```bash
cd weather-detector
```

### Install dependencies

```bash
pip install requests
```

---

## 🔑 API Setup

1. Create a free account on **OpenWeatherMap**.
2. Generate your API key.
3. Replace the API key in the code:

```python
API_KEY = "YOUR_API_KEY"
```
